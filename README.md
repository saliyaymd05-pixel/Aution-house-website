# 🏛️ AuctionHouse — Premium Online Auction Platform

**AuctionHouse** is a luxury online auction web application crafted with HTML5, CSS3, and Vanilla JavaScript. Designed with a dark midnight aesthetic, high-contrast gold accents, and fluid responsiveness, the platform features a full dataset of fine art, rare antiques, vintage automobiles, and luxury horology priced in Indian Rupees (₹).

---

## 🌟 Key Features

* **Curated Dataset (30+ Lots):** Fine art, rare manuscripts, vintage timepieces, luxury cars, fine jewelry, and historic antiques.
* **Indian Rupee (₹) Formatting:** Custom local formatting for multi-lakh and crore bidding increments.
* **Real-Time Live Countdown Timers:** Dynamic countdown timers calculating remaining auction duration down to the second.
* **Interactive Bidding Engine:** Modal popup interface displaying full item details, bid increments, and real-time bid placement.
* **Category Filtering & Search:** Instant multi-category filtering and real-time live search query support.
* **Collector Watchlist & Dashboard:** Dedicated tabs for tracking saved items, reviewing placed bids, and listing new consignment items via LocalStorage.
* **Zero-Dependency Architecture:** Clean, lightweight code without external JS frameworks or heavy build tools.

---

## 🛠️ Tech Stack

* **Structure:** HTML5 (Semantic Structure)
* **Styling:** CSS3 (Flexbox, CSS Grid, CSS Custom Properties)
* **Logic:** Vanilla JavaScript (ES6+, LocalStorage, DOM Manipulation)
* **Typography & Icons:** FontAwesome 6, Google Fonts (*Playfair Display*, *Inter*)
